# Expense Tracker

A full-stack app to track income, expenses, and budgets.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Recharts
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Auth:** JWT, bcrypt

## Features

- Register / Login
- Dashboard with charts
- Add, edit, delete transactions
- Categories and budgets
- Reports
- Dark mode
- Notifications
